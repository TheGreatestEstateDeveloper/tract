# Tract

A field app for Virginia land: tap any parcel to see the owner, acreage, assessed values, last sale and deed reference, zoning against the comprehensive plan, nearby rezoning cases, and home values and land sales around it. Includes builder and developer profiles and a private pipeline.

- Parcel outlines statewide come from VGIN's Virginia Parcels layer.
- County detail is read live from each county's public ArcGIS services (see `js/localities.js`).
- Saved parcels and contacts stay in the browser on each device.

Install: open the site on your phone and choose Add to Home Screen; on a laptop, use the install icon in the address bar.
